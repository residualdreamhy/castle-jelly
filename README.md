# 城堡果冻 · Castle Jelly

一座可以触碰的 WebGPU 微景观。瀑布穿过果冻湖面，在湖底散开。八种鱼在水下巡游，皇家帆船沿岸航行，入夜后亮起两盏暖灯。

## 试玩

下载仓库根目录的 [index.html](index.html)，用支持 WebGPU 的浏览器打开。单文件版自带全部资源，可以离线运行。

- 划过湖面造浪，按住透明切面拖动果冻，双击湖面抛球。
- 选择「投喂糖屑」，再点一下湖面。用切面旁的「观鱼」查看鱼群特写。
- 用右侧面板调整果冻硬度、瀑布流量、波浪阻尼和昼夜。手机上先展开底部面板。

## 源码与构建

| 文件 | 内容 |
| --- | --- |
| [src/app.js](src/app.js) | 三维场景建模、物理模拟、鱼群行为、相机与交互 |
| [src/style.css](src/style.css) | 桌面和移动界面的样式 |
| [src/page.html](src/page.html) | 中文界面模板 |
| [src/vendor/](src/vendor/) | 内嵌的 Three.js 渲染库及其 MIT 许可证 |
| [build.py](build.py) | 将模板、样式、脚本和渲染库合成单文件 |

修改源码后，在仓库根目录运行以下命令。构建只使用 Python 3 标准库。

```sh
python build.py
```
